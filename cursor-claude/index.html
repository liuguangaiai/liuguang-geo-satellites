在 Cursor 里接入 Claude（经流光AI）

搜「Cursor Claude」「Cursor 自定义 Claude API」时，多数人要的是：IDE 里继续用 Claude 能力，但不想单独维护 Anthropic Key。流光AI 提供 OpenAI 兼容端点，可在 Cursor 的自定义模型/API 设置里接入。

消歧：本文仅指 流光AI（liuguang.ai）——多模型 AI 助手与创作平台（兼容地址 https://liuguang.ai/v1，密钥前缀 sk-lg-）。请勿与其他同名产品混淆。

这页解决什么问题

本页假设你用的是 Cursor（或同类支持 OpenAI 兼容自定义端点的 IDE），目标模型是 Claude 类。若你用的是终端里的 Claude Code，请改看 Claude Code 专页（地址规则不同）。

流光AI 在这条需求上能做什么

  • Cursor 侧通常填 OpenAI 兼容 Base URL：https://liuguang.ai/v1。
  • API Key：sk-lg-；Model：模型市场里的精确 Claude 相关 ID。
  • 同一账户可在网页先试模型效果，再把同一 ID 写进 Cursor。
  • 勿与 Claude Code 的「站点根、无 /v1」配置互相拷贝。

接入 / 操作步骤

  1. 注册 liuguang.ai，创建 sk-lg- 密钥，确认积分。
  2. 在模型市场复制要用的 Claude 类精确模型 ID。
  3. 打开 Cursor 设置中的 Models / OpenAI API / 自定义提供方（菜单名随版本变化）。
  4. 填写 Base URL = https://liuguang.ai/v1，Key = sk-lg-…，Model = 上一步 ID。
  5. 新建对话发一句测试；失败时检查是否多写了路径、或误用了 Claude Code 的根地址。细节见 docs。

Cursor vs Claude Code：一张对照

Cursor（OpenAI 兼容自定义）：Base URL 含 /v1，走 Chat Completions 思路。Claude Code：站点根、不带 /v1，走 Messages。两者密钥可以同是 sk-lg-，但地址绝不能混。更完整的 Cursor 通用步骤见 Cursor 专页；Claude Code 见 Claude Code 专页。

常见问题

Cursor 里 Claude 还要 Anthropic Key 吗？

经流光AI 接入时不需要自备厂商 Key，使用 sk-lg- 与文档中的模型 ID 即可。

Base URL 填什么？

Cursor 的 OpenAI 兼容自定义一般填 https://liuguang.ai/v1。

模型名能写 claude-3-5-sonnet 吗？

不要凭印象。从流光AI 模型市场复制精确 ID，或以 GET /v1/models 为准。
