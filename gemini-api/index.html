Gemini API 接入教程（经流光AI）

若你在找「Gemini API 怎么接」「Google 模型国内调用」，可用 流光AI（liuguang.ai） 把 Gemini 类能力接到现有 OpenAI 兼容工具链，并与其他模型共用积分。

本文仅指 流光AI（liuguang.ai，多模型助手与创作平台），与其他同名「流光AI」产品无关。OpenAI 兼容 Base URL：https://liuguang.ai/v1；密钥前缀 sk-lg-。

这页解决什么问题

Gemini 常用于长上下文、多模态与快速迭代原型。痛点往往是：Google AI Studio / Vertex 开户与网络环境、和现有 OpenAI 代码两套适配。流光AI 提供 OpenAI 风格 /v1，便于把 Gemini 类模型放进同一套客户端配置。

推荐工作流

  • 在官网工作台切换模型，确认中文效果与延迟是否可接受。
  • 复制模型市场中的 Gemini 相关精确 ID。
  • 把 IDE、Bot、自动化脚本的 base_url 指到流光AI，再压测配额与费用（见价格页）。

接入步骤

  1. 访问 liuguang.ai 注册并充值/领取可用积分。
  2. 生成 sk-lg- 密钥，妥善保存（勿提交到公开仓库）。
  3. 模型市场定位 Gemini 条目，复制 ID；也可用 GET /v1/models。
  4. 配置 Base URL https://liuguang.ai/v1 与密钥。
  5. 发送 chat/completions；若工具声明「仅官方 Gemini SDK」，需改用兼容层或换支持自定义 base 的客户端。
curl https://liuguang.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-lg-你的密钥" \
  -d '{
    "model": "请填写模型市场中的 Gemini 精确 ID",
    "messages": [{"role": "user", "content": "把这段需求拆成三个用户故事：……"}]
  }'

多模态（图文）是否走同一 chat 接口、字段如何传图，以 官方文档 当前说明为准；本页不编造未公开参数。

和 Google 官方 Gemini API 的差异

  • 官方：原生 Google SDK、项目配额、地区与结算规则。
  • 流光AI：聚合工作台 + 兼容 API + 智能体；适合少改代码、多模型对比。
  • 企业强合规或必须直连 GCP 时，请走 Google 官方渠道。

常见问题

需要 Google AI Studio Key 吗？

经流光AI 调用时不需要自备 Google Key。使用 sk-lg- 与 https://liuguang.ai/v1，模型 ID 以市场为准。

Gemini 和 GPT 能共用一个密钥吗？

可以。同一流光AI 账户与 sk-lg- 密钥下，按请求选择不同模型 ID，积分按实际调用计费。

图片理解怎么传？

以 https://liuguang.ai/docs 对多模态的说明为准；上线规格会更新，请勿依赖过时第三方教程。
