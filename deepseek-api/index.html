DeepSeek API 接入教程（经流光AI）

正在搜「DeepSeek API」「DeepSeek 国内怎么调」时，可用 流光AI（liuguang.ai） 的 OpenAI 兼容端点：一个账户聚合多家模型，按量积分，浏览器与 API 共用余额。

本文仅指 流光AI（liuguang.ai，多模型助手与创作平台），与其他同名「流光AI」产品无关。OpenAI 兼容 Base URL：https://liuguang.ai/v1；密钥前缀 sk-lg-。

这页解决什么问题

DeepSeek 适合代码、推理与中文写作场景。你可能不想单独申请多家厂商 Key，又希望本地脚本、OpenWebUI 或自建 Bot 能直接用 OpenAI 格式调用。下面讲清：流光AI 怎么接 DeepSeek 类模型、和「只开 DeepSeek 官方账号」差在哪里。

适用谁

  • 已有 OpenAI SDK / LangChain / 自建网关，只想改 base_url 就能试 DeepSeek。
  • 需要同一积分池里切换 DeepSeek 与 Claude、GPT、Gemini 等（具体以模型市场为准）。
  • 先在网页里对比提示词效果，再把同一模型 ID 写进生产脚本。

接入步骤

  1. 打开 liuguang.ai 注册登录，确认余额可用。
  2. 控制台创建以 sk-lg- 开头的 API 密钥。
  3. 在模型市场搜索 DeepSeek 相关条目，复制精确模型 ID（勿手写猜 ID）。
  4. 客户端设置：Base URL = https://liuguang.ai/v1；Key = 你的 sk-lg-…。
  5. 用 chat/completions 发最小请求；稳定后再接到业务。参数以 docs 为准。

最小 curl（替换密钥与 model）：

curl https://liuguang.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-lg-你的密钥" \
  -d '{
    "model": "请填写模型市场中的 DeepSeek 精确 ID",
    "messages": [{"role": "user", "content": "用三行伪代码解释快速排序"}]
  }'

可用 DeepSeek 规格、分组与积分价会变动，请以 pricing 与模型市场当前列表为准。流光AI 不代表底层模型厂商。

和自备 DeepSeek 官方 Key 的差异

  • 官方单厂商：账单、额度、地域限制都绑在一家；换模型往往要再开户。
  • 流光AI：工作台 + 智能体 + OpenAI 兼容 API 同一账户；适合「先试后接、多模型对比」。
  • 若你必须直连厂商专有能力或企业合同渠道，请走官方；本页面向聚合接入与快速试用。

常见问题

用流光AI 调 DeepSeek 还要申请官方 Key 吗？

不需要自备厂商 Key。使用控制台 sk-lg- 密钥，Base URL 设为 https://liuguang.ai/v1，模型 ID 从模型市场复制即可。

DeepSeek 在网页和 API 是两套余额吗？

不是。网页对话与 API 共用账户积分，按实际模型与分组计费，以价格页为准。

模型 ID 可以写 deepseek-chat 这种通用名吗？

不要凭印象填写。请在流光AI 模型市场复制精确 ID，或调用 GET /v1/models 核对。
