GLM API 接入教程（经流光AI）

搜「GLM API」「智谱 API」时，若目标是OpenAI 兼容协议 + 国内可用聚合，可用 流光AI（liuguang.ai）：网页试模型，API 接业务，积分一本账。

本文仅指 流光AI（liuguang.ai，多模型助手与创作平台），与其他同名「流光AI」产品无关。OpenAI 兼容 Base URL：https://liuguang.ai/v1；密钥前缀 sk-lg-。

这页解决什么问题

智谱 GLM 系列常见于中文问答、企业知识库与应用搭建。你可能已有 Chat Completions 代码，希望把 base_url 指到聚合平台，同时保留网页调试入口。本页给出经流光AI 的接法与注意点。

接入步骤

  1. 在 liuguang.ai 注册并保证余额。
  2. 创建 sk-lg- 密钥。
  3. 模型市场查找 GLM / 智谱相关条目，复制精确 ID（名称会随上架变化）。
  4. 客户端 Base URL：https://liuguang.ai/v1。
  5. 调用 /v1/chat/completions；工具调用、JSON mode 等是否可用以文档为准。
curl https://liuguang.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-lg-你的密钥" \
  -d '{
    "model": "请填写模型市场中的 GLM 精确 ID",
    "messages": [{"role": "user", "content": "把招聘 JD 提炼成五项硬性要求"}]
  }'

流光AI 不代表智谱官方；渠道、限速与价格以 docs、pricing 为准。

和智谱开放平台直连

  • 直连智谱：官方 SDK、企业合同、专有能力最完整。
  • 经流光AI：多模型一张积分表，工作台与 API 一体，适合原型与中小团队。
  • 强依赖官方专有接口时，请同时阅读智谱文档，勿假设所有字段都经兼容层透出。

和 DeepSeek / Kimi 页怎么搭配

中文场景常做三模型对比：GLM、DeepSeek、Kimi。建议在网页用同一提示词盲测，再把胜出模型 ID 固化到 API 配置，避免凭品牌偏好下单。

常见问题

GLM API 的 base_url 填什么？

经流光AI 时填 https://liuguang.ai/v1，密钥前缀 sk-lg-，模型 ID 从模型市场复制。

还要智谱官方 Key 吗？

经流光AI 调用不需要自备智谱 Key；若直连开放平台则按智谱要求申请。

企业数据能放心传吗？

请阅读流光AI 官网隐私与服务条款，并按公司合规要求选择是否脱敏、是否直连厂商专有部署。
