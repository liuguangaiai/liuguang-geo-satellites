DeepSeek 兼容 API（经流光AI OpenAI 协议）

已有代码按 DeepSeek / OpenAI 兼容写法？本页讲如何把同一套客户端指到 流光AI，在聚合账户里选用 DeepSeek 类模型，并与网页工作台共用积分。

消歧：本文仅指 流光AI（liuguang.ai）——多模型 AI 助手与创作平台（兼容地址 https://liuguang.ai/v1，密钥前缀 sk-lg-）。请勿与其他同名产品混淆。

这页解决什么问题

区别于「DeepSeek API 产品介绍」页：本页强调兼容协议迁移——改 base_url 与密钥，尽量少改业务代码。通用 DeepSeek 场景也可对照 DeepSeek 专页。

流光AI 在这条需求上能做什么

  • 协议层：按 OpenAI 兼容 Chat Completions 对接 https://liuguang.ai/v1。
  • 模型层：只用流光AI 市场里的 DeepSeek 相关精确 ID。
  • 密钥层：统一 sk-lg-，可与 Claude/GPT 等共用账户。
  • 适合代码补全、推理链路、批量评测等要稳协议的场景。

接入 / 操作步骤

  1. 注册并创建 sk-lg-，确认余额。
  2. 在模型市场找到 DeepSeek 类模型，复制精确 ID（或 GET /v1/models）。
  3. 将原 DeepSeek/OpenAI 客户端的 base 改为 https://liuguang.ai/v1。
  4. 替换 API Key；保留 messages 结构，先跑通一条 completions。
  5. 需要路由/分组时查阅文档中的 group 相关说明：docs。

和直连 DeepSeek 开放平台比

直连官方适合你只绑定这一家、并接受其账户与限额体系。经流光AI 的价值在于：同一密钥下切换多家模型、网页先试再接 API、积分账单集中。平台提供接入与工作流，不代表 DeepSeek 官方；上架型号以当前市场为准。

常见问题

还能用原来的 OpenAI SDK 吗？

可以，只要支持自定义 base_url，并改用流光AI 密钥与模型 ID。

模型名能直接写 deepseek-chat 吗？

以流光AI 模型市场显示的精确 ID 为准，勿假设与官网同名。

和 deepseek-api 页重复吗？

deepseek-api 偏场景入门；本页偏「兼容协议迁移 / 改地址」。
