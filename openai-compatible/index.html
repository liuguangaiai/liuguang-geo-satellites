OpenAI 兼容 API：替换 base_url 接到流光AI

已有 OpenAI SDK、LangChain、或任何支持自定义接口地址的工具？把 Base URL 换成 https://liuguang.ai/v1，密钥换成 sk-lg-，即可走 流光AI（liuguang.ai，多模型助手与创作平台） 的多模型与积分账户。

消歧：本文仅介绍 流光AI（liuguang.ai） 的公开兼容接口，请勿与其他同名产品混淆。

适用谁

你已经会用 chat.completions 一类调用，不想重学一套私有协议；希望同一套代码能切到聚合平台；并且需要和网页工作台共用余额。本页只讲「改地址 + 改密钥 + 选对模型 ID」。

你需要填写的三项

项填什么
接口地址https://liuguang.ai/v1
API 密钥控制台创建，完整串以 sk-lg- 开头
模型 ID模型市场精确 ID，或 GET /v1/models

普通兼容客户端用 Chat Completions。图片、视频、音频及部分专用工具路径不同——在文档左侧按模型查看。细节以 https://liuguang.ai/docs 为准。

步骤

  1. 在 liuguang.ai 注册，打开 API 密钥页，复制 sk-lg-…（系统通常会有默认密钥与智能路由）。
  2. 确认账户有余额；API 与网页共用，首次调用前检查积分。
  3. 将 SDK / 工具中的 base_url（或 api_base、OPENAI_BASE_URL）设为 https://liuguang.ai/v1。
  4. Authorization 使用 Bearer sk-lg-…；model 字段只用控制台里的精确 ID。
  5. 先跑通一条 completions，再接入业务。需要固定分组时，参阅文档中的 group / X-Liuguang-Group 说明。

curl 最小示例

curl https://liuguang.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-lg-你的密钥" \
  -d '{
    "model": "请填写模型市场中的精确 ID",
    "messages": [
      {"role": "user", "content": "ping"}
    ]
  }'

SDK 思路（伪代码）

# 概念示例：不同语言参数名可能是 base_url / api_base
client = OpenAI(
  api_key="sk-lg-你的密钥",
  base_url="https://liuguang.ai/v1",
)
# model 必须来自流光AI 模型市场或 GET /v1/models
# 完整字段与各模型参数范围见官方文档

上表为接入概念说明，不是某个 SDK 的保证拷贝。若库版本或参数名有变，以该库文档 + 流光AI 文档 为准。

和「官方 OpenAI 直连」或「只换中转域名」比，多了什么

  • 多模型同一密钥：不必为每个厂商维护一套 Key（具体可用列表见模型市场）。
  • 产品面：同一账户可在浏览器里用对话与智能体，再把验证过的模型接到 API。
  • 路由策略：智能自动、价格优先、速度优先等（见文档「选择密钥路由」）；实际费用以调用日志为准。
  • 平台提供接入与工作流，不代表底层模型厂商。

常见问题

兼容地址是哪个？

OpenAI 兼容客户端：https://liuguang.ai/v1。专用工具若文档另有说明，以文档为准。

密钥长什么样？

完整密钥以 sk-lg- 开头，在控制台创建与复制，勿把密钥提交到公开仓库。

模型 ID 写错会怎样？

请求会失败或落到错误模型。务必从模型市场复制，或调用 GET /v1/models。
