可灵 Kling 与 AI 视频：用流光AI 做片段生成

「可灵 API」「Kling 视频」类搜索，背后多半是要一段能用的 AI 视频。本页介绍 流光AI（liuguang.ai） 的 AI 视频功能与商品短视频智能体；并说明与厂商官方 API 的边界。

本文仅指 流光AI（liuguang.ai，多模型助手与创作平台），与其他同名「流光AI」产品无关。OpenAI 兼容 Base URL：https://liuguang.ai/v1；密钥前缀 sk-lg-。

边界说明

流光AI 提供浏览器内的 AI 视频 与相关智能体，聚合多模型能力。不保证某一时刻一定上架名为 Kling/可灵的具体渠道；请以模型/功能页实时列表为准。若你必须直连快手可灵开放平台，请走厂商官方文档。

网页怎么做出片

  1. 登录 liuguang.ai，确认积分。
  2. 打开 AI 视频：用文字或参考图描述镜头、时长与比例。
  3. 先生成短片段验证运动与主体一致性，再加长或批量。
  4. 电商带货可试 商品短视频：上传商品图与卖点，编辑三镜脚本并导出。
  5. 需要旁白时结合 AI 音频；成片需人工审片。

分辨率、时长上限、积分单价会变，请核对 pricing。生成内容请遵守平台规范与版权要求。

开发者要「Kling API」时怎么做

  • 先查阅 https://liuguang.ai/docs：是否提供视频相关 HTTP 接口、异步任务与回调。
  • 文本模型仍可用 OpenAI 兼容 https://liuguang.ai/v1 + sk-lg- 写脚本、分镜提示词，再在网页提交视频任务。
  • 不要把聊天 completions 的用法生套到未文档化的视频端点。

和「纯 API 中转」叙事

很多 Kling API 页只给密钥与价目。流光AI 的差异是：网页工作台 + 智能体 +（文档范围内的）API 同一账户，适合运营与开发协作，而不是只卖通道。
