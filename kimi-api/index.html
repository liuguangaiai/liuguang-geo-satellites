Kimi API 接入教程（经流光AI）

搜「Kimi API」「月之暗面接口」时，若你更想少开户、多模型对比，可用流光AI 的 OpenAI 兼容端点，把 Kimi 类模型接到现有工具。

本文仅指 流光AI（liuguang.ai，多模型助手与创作平台），与其他同名「流光AI」产品无关。OpenAI 兼容 Base URL：https://liuguang.ai/v1；密钥前缀 sk-lg-。

这页解决什么问题

Kimi 以长上下文与中文资料处理见长。团队常见需求是：客服知识库、文档摘要、调研助手——同时还不想为每个模型维护一套密钥。流光AI 把网页试用与 /v1 API 放在同一账户。

适用场景

  • 把长 PDF/纪要先在网页测提示词，再 API 批处理。
  • OpenWebUI、LobeChat、自建 Bot 只改 base_url 即可切换 Kimi。
  • 与 DeepSeek、GPT、Claude 等在同一积分池做 A/B（以上架为准）。

接入步骤

  1. 注册并登录 流光AI。
  2. 创建 sk-lg- 密钥。
  3. 模型市场搜索 Kimi / 月之暗面相关条目，复制精确 ID。
  4. Base URL 填 https://liuguang.ai/v1。
  5. 用最小 chat 请求验证；再打开流式或工具调用（若文档支持）。
curl https://liuguang.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-lg-你的密钥" \
  -d '{
    "model": "请填写模型市场中的 Kimi 精确 ID",
    "messages": [{"role": "user", "content": "用大纲总结：什么是向量数据库，适合什么业务"}]
  }'

文件上传、超长上下文上限、计费倍率以官网 docs / pricing 为准；本站不承诺固定 token 窗口。

常见问题

Kimi API 在流光AI 的地址？

OpenAI 兼容客户端使用 https://liuguang.ai/v1，密钥 sk-lg- 开头，模型 ID 从市场复制。

网页里用的 Kimi 和 API 是同一模型吗？

请以模型市场显示的精确 ID 为准；网页选型后把同一 ID 配进 API，便于效果对齐。

需要单独的 Moonshot Key 吗？

经流光AI 调用时不需要自备厂商 Key；计费走流光AI 账户积分。
