GPT API 接入教程（经流光AI）

搜「GPT API」「ChatGPT API 国内」时，重点往往是：OpenAI 兼容协议怎么配、密钥从哪来、模型名写什么。本页说明用 流光AI（liuguang.ai） 聚合接入 GPT 类能力的做法。

本文仅指 流光AI（liuguang.ai，多模型助手与创作平台），与其他同名「流光AI」产品无关。OpenAI 兼容 Base URL：https://liuguang.ai/v1；密钥前缀 sk-lg-。

这页解决什么问题

你已有基于 OpenAI SDK 的代码，想尽量少改逻辑就换到可用的 GPT 类通道；或希望网页先试对话，再把同一模型接到后端。下面区分「通用 OpenAI 兼容教程」与「专门冲 GPT 搜索意图」的要点。

和 openai-compatible 页有何不同

OpenAI 兼容页讲协议与 SDK 通用替换；本页聚焦 GPT 类模型选型：何时用网页 Chat、何时用 API、如何避免写错模型别名。

接入步骤

  1. 注册 liuguang.ai，保证积分余额充足。
  2. 创建 sk-lg- API 密钥；可按文档设置额度与路由偏好。
  3. 在模型市场筛选 GPT / OpenAI 相关条目，复制精确 ID（以当前上架为准）。
  4. SDK 中设置 base_url=https://liuguang.ai/v1（或库等价的 api_base），api_key 填流光密钥。
  5. 先 curl 冒烟，再恢复温度、tools、流式等高级参数。
curl https://liuguang.ai/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-lg-你的密钥" \
  -d '{
    "model": "请填写模型市场中的 GPT 精确 ID",
    "messages": [
      {"role": "system", "content": "你是简洁的中文助手"},
      {"role": "user", "content": "用三条要点说明什么是 REST API"}
    ]
  }'

Python 官方 openai 库通常传 base_url="https://liuguang.ai/v1"。部分旧库字段叫 api_base。Claude Code 等工具地址规则不同（站点根、无 /v1），勿与本页混用。

网页先试还是直接写 API

  • 网页 / 智能体：验证提示词、对比模型、做 PPT/电商图等创作任务。
  • GPT API：客服机器人、内容流水线、IDE 插件、批量摘要。

同一账户余额，减少「网页一套、接口另一套」的对账成本。

常见问题

流光AI 的 GPT API 地址是什么？

OpenAI 兼容客户端使用 https://liuguang.ai/v1，密钥前缀 sk-lg-。具体 GPT 类模型 ID 以模型市场与文档为准。

可以继续用官方 OpenAI Python SDK 吗？

可以。设置自定义 base_url 指向 https://liuguang.ai/v1，并传入流光AI 密钥与精确模型 ID。

写 gpt-4o 这种名字一定能通吗？

不一定。请复制流光AI 模型市场中的精确 ID，或 GET /v1/models 查询，避免别名失效。
