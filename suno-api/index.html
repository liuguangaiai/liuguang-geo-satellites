接入 / 操作步骤

  1. 登录 liuguang.ai，在工作台或智能体中查找音乐/音频相关能力并试用。
  2. 若需程序化调用：创建 sk-lg-，打开文档左侧按模型/模态筛选。
  3. 确认文档给出的 endpoint、参数与示例；不要套用纯文本 chat 的路径想当然。
  4. 用文档中的最小示例替换密钥后试调。
  5. 对照 pricing 理解积分消耗。

和「只转聊天模型」中转的差异
