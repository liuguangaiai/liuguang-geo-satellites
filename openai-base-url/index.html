OpenAI Base URL 改成流光AI：https://liuguang.ai/v1

搜索词往往就是「openai base url」「OPENAI_BASE_URL」「api_base」。本页只回答：接到 流光AI（liuguang.ai） 时，Base URL / api_base 应该填什么、密钥长什么样、模型 ID 从哪抄。

消歧：本文仅指 流光AI（liuguang.ai）——多模型 AI 助手与创作平台（兼容地址 https://liuguang.ai/v1，密钥前缀 sk-lg-）。请勿与其他同名产品混淆。

这页解决什么问题

你已经有一段 OpenAI SDK 或兼容代码，只差改环境变量或构造函数里的 base。不讲产品百科，只讲这一行配置怎么对。

流光AI 在这条需求上能做什么

  • 标准值：https://liuguang.ai/v1（注意末尾通常不要再拼 /chat/completions，由 SDK 自己加路径）。
  • 密钥：sk-lg- 前缀；环境变量常见为 OPENAI_API_KEY。
  • 模型：必须是流光AI 侧精确 ID，不是口头俗称。
  • Claude Code 等特例不用这个 /v1 地址——见 Claude Code 专页。

接入 / 操作步骤

  1. 拿到 sk-lg- 密钥并确认账户有余额。
  2. 设置 Base URL / OPENAI_BASE_URL / api_base = https://liuguang.ai/v1。
  3. 设置 API Key = 完整 sk-lg-…。
  4. 用 GET https://liuguang.ai/v1/models 或模型市场确认可用 ID。
  5. 调用 chat completions；若 404，检查是否重复拼接了 /v1。文档：docs。

配置 / 自检示例

# 环境变量思路（名称因工具而异）
export OPENAI_BASE_URL="https://liuguang.ai/v1"
export OPENAI_API_KEY="sk-lg-你的密钥"

# curl 自检（model 换成市场精确 ID）
curl "$OPENAI_BASE_URL/chat/completions" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"请填写精确ID","messages":[{"role":"user","content":"ping"}]}'

常见填错方式

① 写成 https://liuguang.ai/v1/chat/completions 当 base（多数 SDK 会再拼一次路径）。② 漏写 /v1（普通兼容客户端需要它）。③ 把 Claude Code 的根地址拷到 OpenAI SDK。④ 模型 ID 用公开俗称而非市场精确值。价格与可用模型以 pricing 为准。
